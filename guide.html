Eyepiece Guide

This guide will walk you through the eyepiece app with a series of little tutorials (You can reset the app by reloading the page).
  • Press the Compute field button once and then press Delete field.
  • Press the Compute field button twice and then press Delete field twice
  • Reset the app
  • Select Reset random distributions
  • Press the Compute field button three times and then press Delete field until the drop down list is empty
  • Reset the app
  • Set Star # to 3
  • Press Compute field
  • Change the camera band from K to J
  • Press Compute field
  • Using the drop-down list, select the K band frame
  • Change the camera band from K to V
  • Press Compute field
  • Using the drop-down list to cycle through K, J and V frames
  • Reset the app
  • Set Star # to 3
  • Set the star magnitudes Std (standard deviation) to 0
  • Press Compute field
  • Set the star magnitudes Std (standard deviation) to 1
  • Press Compute field
  • Set the star magnitudes Std (standard deviation) to 2
  • Press Compute field
  • Reset the app
  • Set the star spatial distribution to Globular
  • Set Star # to 10
  • Set the star globular cluster Radius to 0.1 arcsec
  • Set the star magnitudes Std to 0
  • Press Compute field
  • Select the JWST telescope
  • Press Compute field
  • Select the GMT telescope
  • Press Compute field
